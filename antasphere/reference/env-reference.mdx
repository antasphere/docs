Every variable the server reads, generated from the zod env schema
(`apps/server/src/env.ts`) so this reference cannot drift from the code
that parses the environment. The app refuses to boot on an invalid
environment and prints a readable table of problems.

Do not edit this page by hand: run `pnpm --filter @antasphere/server docs:env`
after changing the schema.

## Required

| Variable       | Type   | Default | Description                                             |
| -------------- | ------ | ------- | ------------------------------------------------------- |
| `DATABASE_URL` | string | —       | Postgres connection string. The only required variable. |
