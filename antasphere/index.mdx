One account for every Antasphere tool: sign in once at
[account.antasphere.com](https://account.antasphere.com) and you are
connected everywhere. Slideless is the first tool built on it, and every
tool in the family authenticates against the same identity, the same
organizations, and the same credentials.

Under the hood, the account service is an OpenID Connect identity provider
with an account layer on top: open sign-up, a personal organization
provisioned automatically, shared organizations with invitations and roles,
API keys, self-service account management (including optional 2FA), an
audit log, and GDPR export and delete. First-party tools federate against
it ("Sign in with Antasphere"), so one login carries across the whole
product family. Agents are first-class consumers too: every instance
serves a built-in MCP endpoint, and the `antasphere` CLI signs in with a
one-time email code.
