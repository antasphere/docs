Every command can name the workspace it works in: `--workspace`, `SLIDELESS_WORKSPACE`, or a field of the saved profile, and `slideless workspaces` lists yours. The reference commands arrive: brands and templates are decks the workspace shares, and `slideless brand` / `slideless template` list, pull, push, publish and start from them.
